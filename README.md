# ⚽ FootVision

FootVision is a Machine Learning-based football match prediction web application developed using Flask and Scikit-learn. It predicts the probability of a Home Win, Draw, or Away Win using a Logistic Regression model trained on historical football match data.

The application allows users to register, log in, submit match predictions, and compete on a leaderboard based on the accuracy of their predictions.

## Features

- User Registration and Login
- Machine Learning-based Match Outcome Prediction
- Win / Draw / Loss Probability Prediction
- Match Score Prediction
- First Goalscorer Prediction
- Leaderboard System
- Admin Match Result Management
- Responsive Web Interface
